# effects_engine

Das ist der Code der Effects Engine.

Wenn du hier hineinschaust, bist du bereits im internen Framework-Code und nicht mehr in der normalen Benutzeroberflaeche des Repos.

## Fuer Nutzer

Wenn du nur Lichter anzeigen willst, fang nicht hier an, sondern bei:

- `docs/getting_started.md`
- `docs/effects_engine_2_minuten.md`
- `docs/effects_engine_tutorial.md`

## Was in diesem Ordner liegt

- `easy.py` – sehr einfache API fuer direkte Nutzung
- `effects.py` – allgemeine Effektbausteine
- `advanced_effects.py` – weitere Anzeigearten
- `config_loader.py` – JSON/YAML laden
- `controller.py` – State/Event-Steuerung
- `backend.py` – Hardware- und Test-Backends

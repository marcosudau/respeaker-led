# effects

Hier liegen die dateibasierten Effektmodule fuer den laufenden Service.

Jede Python-Datei in diesem Ordner kann eine oder mehrere `BaseEffect`-Unterklassen enthalten.

Die Default-Registry des Services scannt diesen Ordner automatisch beim Start.

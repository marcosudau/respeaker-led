# Dokumentationsarchiv

Dieser Ordner bewahrt historische, abgeloeste, doppelte und auch leere
Dokumentationsstaende. Seine Inhalte sind **nicht normativ** und duerfen nicht
als Beschreibung des aktuellen Systems verwendet werden.

## Bereiche

- [Projektgeschichte und alte Planung](project-history/README.md)
- [Historische Effektkonzepte](effect-concepts/README.md)
- [Sanierungsberichte](sanitation-reports/README.md)
- [Abgearbeitete Prompts](prompts/README.md)
- [Migrationsmanifest](MIGRATION.md)

## Umgang mit dem Archiv

- Dateien bleiben inhaltlich unveraendert.
- Alter und neuer Pfad werden im Migrationsmanifest dokumentiert.
- Leere oder redundante Dateien werden sichtbar gekennzeichnet, nicht
  geloescht.
- Aktuelle Nachfolgedokumente werden verlinkt.
- Interne Aussagen im Archiv koennen dem aktuellen System widersprechen.

Verbindliche Dokumentation beginnt unter [Dokumentation](../index.md).

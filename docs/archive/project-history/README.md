# Projektgeschichte

Entwicklung und Dokumentation.

## Inhalt

- `planning/`: alte Zielbilder, Umbau- und Deploymentplaene
- `development/`: abgeloeste Entwicklernotizen und Layerbeschreibung
- `history_and_legacy/`: zusammengefasste Projektgeschichte
  einschliesslich einer bei der Sanierung wiedergefundenen abweichenden Revision
- `replaced-current-docs/`: fruehere Seiten, die durch die neue Referenz
  ersetzt wurden
- `documentation-restructure/`: Fahrplan und Abschlussstand der
  Dokumentationsneuordnung

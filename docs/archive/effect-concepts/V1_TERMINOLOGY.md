# Historische V1-Begriffe

Diese Tabelle dient nur zum Lesen alter Archivunterlagen. Sie ist keine
Migrationsunterstuetzung und kein Bestandteil des aktuellen Vertrags.

| Historischer Begriff | Aktuelle Einordnung |
|---|---|
| generischer Effekt | konkrete State-, Overlay- oder Event-Definition |
| Effect-Preset als eigener Typ | optionales Preset einer Definition |
| Embedded Effect Command | Steuerungskommando oder Integration |
| `MAIN_LAYER` | kein oeffentliches V2-Konzept |
| Effekt waehlt einen Layer | Typvertrag bestimmt die interne Platzierung |
| gemeinsame `common.py` | in V2 fuer Effektlogik verboten |
| Quelle unter `build/` | autoritative Quellen liegen ausserhalb des Buildoutputs |

Die verbindlichen Begriffe stehen unter
[Begriffe und Systemobjekte](../../effect-system/02_vocabulary.md).

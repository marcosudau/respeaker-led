# Tutorial-Effektquellen

Diese drei Pakete sind die vollstaendigen Ergebnisse der Lernanleitungen:

- `states/example_rotation`
- `overlays/example_doa`
- `events/example_short_pulse`

Sie sind validierbar, paketierbar und testbar, werden aber weder automatisch
registriert noch in `default-effects.lefxset` aufgenommen. Der gemeinsame
LEFXSET-Build ist in
`../../effect-development/tutorials/build_packages.md` beschrieben.
